# 🐾 Petshop Amigo Fiel — Fase 1 (HTML5)

Projeto acadêmico desenvolvido para a disciplina de **Fundamentos de Sistemas Web** (Fase 1). O objetivo desta etapa é a construção da estrutura base do site de um petshop utilizando exclusivamente **HTML5 semântico**, priorizando boa legibilidade do código, acessibilidade e organização do conteúdo.

---

## 📌 Sobre o Projeto

O **Petshop Amigo Fiel** é uma aplicação web focada na apresentação de produtos e serviços para animais de estimação. Nesta primeira fase, foi desenvolvida toda a estrutura de marcação da página única (*landing page*), contendo catálogo por categorias, tabela de serviços e informações de contato.

---

##  Tecnologias Utilizadas

* **HTML5:** Estruturação semântica de todo o conteúdo.
* **CSS (Básico):** Padronização de dimensões e proporções de imagens via marcação interna/estilo básico.
* **Hospedagem Externa de Mídia:** Vinculação de imagens via URLs externas para manter o repositório leve.

---

##  Estrutura do Código & Boas Práticas

O código foi construído seguindo os padrões do HTML5 semântico:

* `<header>` e `<nav>`: Cabeçalho principal com menu de navegação por âncoras.
* `<main>`: Bloco principal englobando as seções da página.
* `<section>` e `<article>`: Organização lógica dos produtos (divididos em Ração, Higiene e Acessórios) e dos serviços oferecidos.
* `<footer>` e `<address>`: Rodapé da página com informações institucionais, links rápidos e dados de contato.
* `<img>`: Inserção de imagens via links externos com uso do atributo `alt` para acessibilidade.
